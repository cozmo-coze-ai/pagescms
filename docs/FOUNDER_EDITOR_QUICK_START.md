# Change the COZE website in ChatGPT

You do not need GitHub, coding or any technical setup.

1. Open **COZE Homepage & Itinerary Editor** from the plugin link shared with you.
2. Select **Install**, then **Connect** if prompted. Use your own COZE connection
   key in the sign-in form supplied by the COZE administrator. Never paste it into chat.
3. Start a new ChatGPT chat and select **@COZE Homepage & Itinerary Editor**.
4. Send:

   > Show my homepage connection and list our itineraries. Do not change or publish anything.

After the connection works, try:

> Make the homepage hero more compact on mobile. Keep our colors and wording. Show me the preview before publishing.

Or:

> Make the introduction of [itinerary name] shorter. Keep the prices, dates and included services unchanged. Show me the preview first.

Check the preview. Say **yes** only when you want that exact change published.
The editor will tell you when the website has actually updated.

You can edit the allowed homepage design, photos and four-language text, plus
existing itinerary content and photos. Booking, payment and guest-message systems
are outside this editor.

If you use both personal ChatGPT and COZE HOSPITALITY 3.0, installation and
connection may be needed in each. If the plugin or connection is unavailable,
ask the COZE administrator to enable it; you do not need to create a GitHub account.
